## 3. ホスト版の利用条件とレート制限 / Hosted Edition Usage & Rate Limits

- **読み取り専用・匿名アクセス**: ホスト版は認証不要の読み取り専用（read-only）MCP サーバーとして提供されます。
- **レート制限と禁止行為**:
  - 安定したサービス提供および個人事業者の登録番号に対する総当たり照会防止のため、接続元 IP アドレス単位でのレート制限（原則として `/mcp` エンドポイントは 1分あたり 60 リクエストまで）を設けています。
  - 短時間に大量のリクエストを送信する行為、登録番号（`T` + 13桁）を機械的に連番生成して総当たり照会する行為、またはサービスの運営を妨害する行為を禁止します。
- **データの基準日（月1回更新）**:
  - ホスト版のデータベースは月1回（前月末時点の全件データ）で更新されます。月途中の変更・新規登録・取消・失効・削除（処理区分 99 等）は次回の月次更新まで反映されないため、最新状態の最終確認は国税庁の各公表サイトで行ってください。

## 4. ローカル実行版における国税庁 Web-API アプリケーション ID の取扱い / NTA Application ID (Self-Hosted Edition)

ローカル実行版（セルフホスト）において国税庁 Web-API を直接呼び出す場合、利用者自身が国税庁へ届け出て取得したアプリケーション ID を環境変数 `NTA_APPLICATION_ID` に設定する必要があります。法人番号システム Web-API 機能利用規約に基づき、以下の事項を守ってください。

- 取得したアプリケーション ID を第三者に譲渡・貸与・開示・共有しないこと（同規約 第9条第1項第五号）。ホスト版では国税庁 Web-API のアプリケーション ID を使用せず、公開ダウンロードデータを当社のデータベースに取り込んで提供しています。
- 短時間に大量のアクセスを行わないこと（同規約 第9条第1項第三号。本ソフトウェアの Web-API クライアントには、既定で毎秒1リクエストのレート制限機能を内蔵しています）。
